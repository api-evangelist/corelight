# Corelight

> Corelight is a network detection and response (NDR) company founded by the creators of the open-source Zeek (formerly Bro) network security monitor. Its Open NDR Platform turns network traffic into high-fidelity security evidence — logs, alerts, and metadata — for threat detection, hunting, investigation, and incident response across on-premises and cloud environments. Corelight Sensors expose a comprehensive RESTful API for remote configuration and control, driven by the open-source corelight-client CLI, with a Fleet Manager for centralized management.
